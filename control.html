Logic & Control Structures

Level 04: Mastering Decision Making and Loop Logic in Problem Solving

Why Control Structures Matter?

In the real world, problems are rarely linear. Computers need to make choices (Selection) and perform repetitive tasks (Repetition) to solve complex issues. Control structures are the "Traffic Lights" of your algorithm—they tell the data where to go and when to stop.

In CSC402, mastering these structures is the difference between a simple calculator and a fully functional program.

The Tools of Logic

Relational operators are the heart of decision-making in CSC402.

> Greater Than

Checks if the left value is strictly more than the right. Useful for checking if a student passed a hurdle.

if (score > 50)
< Less Than

True if the left side is smaller. Best for checking budget limits or inventory warnings.

if (price < 100)
== Equal To

Checks for an exact match. Remember: C++ uses == for comparison, not a single =!

if (ans == "Yes")
!= Not Equal

Used to keep a loop running until a specific value (sentinel) is entered by the user.

while (n != -1)
>= Greater or Equal

Includes the boundary number. True if value is at least 18 or more.

if (age >= 18)
<= Less or Equal

True if the value is 10 or less. Perfect for "max capacity" or "out of stock" logic.

if (qty <= 10)

Logical Connectives

Used to combine multiple relational expressions into one complex decision.

&& (Logical AND)

Both conditions MUST be true for the whole thing to pass.

if (age >= 18 && license == "Yes")
Requirement: 100% Truth
|| (Logical OR)

Only ONE of the conditions needs to be true.

if (day == "Sat" || day == "Sun")
Requirement: At least one True
! (Logical NOT)

Reverses the result. Turns True to False.

while (!gameOver)
Requirement: Flip the result
^ (Logical XOR)

True only if exactly one condition is true.

if (coffee ^ tea) // Cannot be both true
Requirement: Differing results

Execution Logic: The 3 Patterns

float length, width, area;

area = length * width;

How to Use the Simulator

Follow these steps to see how a Sequence Structure works in real-time:

1
Input Phase: Type your numbers into the Length and Width boxes. This simulates the cin (READ) process where the computer waits for your data.
2
Trigger: Click the "Calculate Area" button. This tells the CPU to move from the input stage to the processing stage.
3
Processing & Output: The code executes the math length * width and immediately triggers cout (DISPLAY) to show the result on the screen.
Useful Learning Tips:
  • Declaration Matters: In C++, you can't just use area. You must declare it first (e.g., float area;) or the compiler will crash.
  • The Order Rule: You cannot calculate area before you read the length. Always ensure your cin comes before your math logic.
  • Semicolons: Unlike pseudocode, every single line in your C++ sequence must end with a ; or it won't run!
Note: This linear flow is the "foundation." Once you master this, you can move to Selection (if/else) and Repetition (loops).

Selection Simulation Guide

Selection logic is about making choices. Follow these steps to test the C++ branching logic:

1
Input Variable Data: Enter values for score and attendance. The computer stores these to evaluate the if conditions.
2
Test the OR (||): Set Score to 85 and Attendance to 0. You still win! This shows that OR only needs one side to be true to execute the block.
3
Test the AND (&&): Set Score to 55 and Attendance to 70. Even though the score is passing, the result is "Retake." Why? Because AND is strict—both must be true.
4
Observe the Sequence: Notice that if the first if is met, the computer ignores all else if blocks below it. This is called "Mutual Exclusion."
CSC536 Learning Tips:
  • Syntax Check: In C++, never put a semicolon after the if(...) line. If you do, the computer thinks the "choice" is empty!
  • The == Mistake: When checking for equality in an if, always use ==. Using a single = will overwrite your variable instead of comparing it.
  • Flowchart Tip: In your lab report, every if or else if must be represented by a Diamond Shape in your flowchart.
Pro Tip: Always use the else block as a "safety net" to catch any cases that don't fit your specific conditions.
negative_loop.cpp
bool exit_signal = false;
string user_input;
while (!exit_signal) {
cout << "System running... Type STOP to exit: ";
cin >> user_input;
if (user_input == "STOP") {
exit_signal = true;
}
}

Repetition Simulation Guide

This simulation demonstrates a Sentinel-Controlled Loop. It uses a "Flag" to decide when to stop repeating:

1
The Initial State: In C++, we set bool exit_signal = false;. The loop condition (!exit_signal) translates to "while NOT true," which allows the code to enter the loop for the first time.
2
Processing Input: Type any word. As long as it isn't the sentinel value, the if condition remains false, the flag stays false, and the loop repeats.
3
The Sentinel Trigger: Type exactly STOP. The C++ == operator matches the string, triggering the update: exit_signal = true;.
4
The Exit: The loop returns to the top. It checks !true (which is false). Since the condition is no longer met, the program jumps to the code after the }.
CSC536 Learning Tips:
  • Case Sensitivity: In C++, "STOP" is not the same as "stop". If the user types lowercase, your loop might become an Infinite Loop!
  • The "!" Operator: Always remember that ! is the logical NOT. It is essential for "Negative Logic" loops where you run until something happens.
  • Memory Management: Using a bool flag is more memory-efficient than repeatedly checking a long string inside the loop condition header.
Exam Prep: When drawing the flowchart for this, ensure the "False" path of your diamond leads to the end of the program.

The "Golden" Logic Patterns (Interactive C++)

Master the two most important patterns for CSC536. Use the simulators below to see how data flows through the logic.

The Accumulator

Used to calculate a running total (Sum).


float total = 0.0; // Start at zero
for(int i=0; i < 3; i++) { 
  cout << "Enter price: ";
  cin >> price;
  total = total + price; 
}
cout << "Final Sum: " << total;
> Output Result...
Code Explanation:
  • Line 1 (Initial): We set total to 0 outside the loop so it doesn't reset.
  • Line 4 (Update): The "Accumulator" math total = total + price takes the old total and adds the new input.
  • Important: In your C++ compiler, don't forget #include <iostream> at the top!

The Extreme Finder

Used to find the Maximum or Minimum value.


cin >> firstVal;
float max = firstVal; // Set first as "Champ"
while(data_exists) { 
  if(newVal > max) { 
    max = newVal; // New champion found!
  }
}
cout << "Highest: " << max;
> Output Result...
Code Explanation:
  • Line 2 (Logic): We assume the first input is the max.
  • Line 4 (Compare): The if statement acts as a filter; it only updates max if the new number is bigger.
  • What to insert: Use this logic for C++ tasks like "Find the student with the highest mark."
