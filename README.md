# CSC536: Algorithmic Problem Solving Learning Portal 🚀

### *Master the Logic of C++ Before You Write a Single Line of Code*

## 🎓 Project Overview

**Algorithmic Problem Solving** is the bridge between human logic and machine execution. This multimedia web platform is designed specifically for C++ beginners to master the "problem-solving" phase of development. By focusing on **Sequence**, **Selection**, and **Repetition** structures, students build a strong mental framework using flowcharts and pseudocode before grappling with complex C++ syntax.

## 🎯 Learning Objectives

Our mission is to transform novice learners into logical thinkers through:

* **Conceptual Foundations:** Understanding the "why" behind algorithm design.
* **Visual & Verbal Logic:** Mastery of flowcharts and pseudocode as blueprints for code.
* **Structural Proficiency:** Deep dives into the three pillars: **Sequence, Selection, and Repetition.**
* **Syntax Readiness:** Building confidence so that transitioning to C++ code feels intuitive.

## 🧠 Educational Framework: Gagné’s Nine Events

To ensure effective knowledge transfer, this portal is structured around **Robert Gagné’s Instructional Design Theory**:

| Event | Implementation in Portal |
| --- | --- |
| **1. Gain Attention** | Introduction to real-world programming challenges. |
| **2. Inform Learners** | Transparent module-based learning objectives. |
| **3. Stimulate Recall** | Reviewing foundational logic before moving to complex structures. |
| **4. Present Content** | Multi-modal delivery using text, interactive diagrams, and symbols. |
| **5. Provide Guidance** | Step-by-step walkthroughs of algorithm construction. |
| **6. Elicit Performance** | Hands-on interactive tutorials. |
| **7. Provide Feedback** | Real-time validation of quiz answers. |
| **8. Assess Performance** | Integrated scoring system to measure module mastery. |
| **9. Enhance Retention** | Practical bridging exercises to prepare for C++ implementation. |

---

## 💻 Key Technical Features

* **Smart Quiz Engine:** Features randomized question shuffling and dynamic feedback (FAILED, GOOD, CONGRATULATIONS) to keep learners engaged.
* **Logic Visualizations:** Interactive modules explaining complex `IF-THEN-ELSE` and `XOR` logic gates.
* **Modern Web Stack:** Built on **Bootstrap 5.3.3**, ensuring a fully responsive experience across mobile, tablet, and desktop.

## 🚀 Getting Started

Setting up the portal locally is quick and requires no compilation:

1. **Clone** this repository to your computer.
2. Navigate to the project root directory.
3. Launch the platform by opening `index.html` in any modern web browser.
