Level 03: Designing Algorithms with Pseudocode

What is Pseudocode?

Pseudocode is a "fake" code. It is a high-level description of an algorithm that uses the structural conventions of programming languages but is intended for human reading rather than machine reading.

In CSC402, we use it to focus on the logic without worrying about semicolons, curly braces, or complex syntax rules.

Core Keywords

Click or hover over the cards to see how we define instructions in pseudocode.

START / END

The boundaries of your algorithm. Every process must have these.

READ / GET

Used when the program needs to receive input from the user.

SET / COMPUTE

Used for calculations and assigning values to variables.

DISPLAY / PRINT

Used to output the result or message to the screen.

The Writing Standards

Pseudocode is the bridge between human thought and computer logic. In CSC402, clarity is more important than semicolons. Follow these three standard patterns to ensure your logic is exam-ready.

01

The IPO Standard (Input-Process-Output)

The foundation of every algorithm. This standard ensures that data flows in a single direction without confusion.

  • Keywords: Always use READ for input and DISPLAY for output.
  • Variable Naming: Use CamelCase or snake_case (e.g., totalPrice). Avoid single letters like x or y.
  • Start/End: Every sequence must be wrapped in START and END tags.
Standard basic_calculation.ps
START
READ hoursWorked, hourlyRate
SET grossPay = hoursWorked * hourlyRate
DISPLAY grossPay
END
02

The Selection Hierarchy

In CSC402, branching logic must be visually clear. This standard focuses on the "Scope" of a decision.

  • The ENDIF Rule: Every IF must have a closing ENDIF to prevent "Dangling Else" errors.
  • Indentation: Each level of nesting must be indented by 4 spaces (or 1 tab) to show ownership.
  • The THEN Keyword: Unlike C++, pseudocode uses THEN to signify the start of the "True" block.
Standard nested_logic.ps
IF score >= 80 THEN
DISPLAY "A"
ELSE
IF score >= 50 THEN
DISPLAY "Pass"
ELSE
DISPLAY "Fail"
ENDIF
ENDIF
03

Sentinel Loop Control

Loops that run until a specific value is entered require a "Double Read" pattern to be considered valid pseudocode.

  • The Prime Read: You must READ the variable once before the loop begins.
  • The Update Read: You must READ the variable again as the last line inside the loop.
  • Condition Check: The WHILE condition should always check for the "End Value" (e.g., != -1).
Standard sentinel_pattern.ps
READ grade // Prime Read
WHILE grade != -1 DO
SET total = total + grade
READ grade // Update Read
ENDWHILE
DISPLAY total

Bridging the Gap: Logic vs. Syntax

Moving from human logic to machine code can be confusing. Hover over a logic step in the Pseudocode to see its equivalent in C++.

Pseudocode Human Logic

The "Blueprint" used in CSC402 exams.

logic_only.ps
READ age
IF age >= 18 THEN
DISPLAY "Eligible"
ELSE
DISPLAY "Minor"
ENDIF
C++ Syntax Machine Strict

The implementation in the lab.

main.cpp
cin >> age;
if (age >= 18) {
cout << "Eligible";
} else {
cout << "Minor";
}
Input Method

READ is simplified. In C++, we use cin (Character Input).

Scope Control

Pseudocode uses ENDIF. C++ uses curly braces {} to group logic.

Output Method

DISPLAY maps directly to cout (Character Output).
